# OpenCV Image Processing Experiments

## Overview
This repository contains basic **OpenCV Image Processing** experiments implemented in **Python**. These programs demonstrate common image processing techniques such as grayscale conversion, blurring, edge detection, image transformations, morphological operations, video processing, and image sharpening.

## Requirements

- Python 3.x
- OpenCV
- NumPy

Install the required packages:

```bash
pip install opencv-python numpy
```

## Folder Structure

```
OpenCV-Experiments/
│── image.jpg
│── experiment01.py
│── experiment02.py
│── ...
│── experiment20.py
└── README.md
```

## Experiments Included

1. Convert an Image to Grayscale
2. Blur an Image
3. Detect Image Outline using Canny
4. Dilate an Image
5. Erode an Image
6. Perform Basic Video Processing
7. Scale an Image (Bigger and Smaller)
8. Rotate an Image (Clockwise & Counter Clockwise)
9. Translate (Move) an Image
10. Affine Transformation
11. Perspective Transformation
12. Homography Transformation
13. Direct Linear Transformation (DLT)
14. Edge Detection using Canny
15. Edge Detection using Sobel X
16. Edge Detection using Sobel Y
17. Edge Detection using Sobel XY
18. Image Sharpening using Laplacian Mask

## How to Run

1. Place the input image (`image.jpg`) in the project folder.
2. Open the project in Visual Studio Code or any Python IDE.
3. Run the desired experiment:

```bash
python experiment01.py
```

4. Press any key to close the output window.

## Expected Output

Each experiment displays:
- Original Image
- Processed Image

The output varies depending on the selected image processing operation.

## Learning Outcomes

After completing these experiments, students will be able to:

- Read and display images using OpenCV.
- Perform image enhancement operations.
- Apply morphological operations (Erosion & Dilation).
- Perform geometric transformations.
- Detect edges using Canny and Sobel operators.
- Apply affine, perspective, homography, and DLT transformations.
- Process video frames using OpenCV.
- Sharpen images using Laplacian filters.
